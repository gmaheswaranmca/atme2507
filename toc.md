# 📅 Data Engineering Course Schedule (Phase 2)

## Day 1-2: Python Foundation & Data Engineering Introduction
**Duration:** 3.5 Hours each (7 Hours Total)

### What is Data Engineering?
- Real-world examples (Netflix, Uber, Amazon)
- Data Engineer vs Data Scientist vs Data Analyst
- Career opportunities in Data Engineering

### Python Basics Refresher
- Variables, data types, lists, dictionaries
- Functions and basic OOP concepts
- **Hands-on:** Simple calculator program

### Data Formats
- CSV, JSON, XML overview
- When to use which format
- Sample data files exploration

### File Operations in Python
- Reading/Writing text files
- Working with CSV files (manual parsing)
- JSON file handling
- Error handling with try-except

### Pandas Refresher
- What is pandas and why use it?
- Reading CSV files with pandas
- Basic DataFrame operations
- Viewing data: head(), info(), describe()

### Hands-on Practice
- Load and explore different data formats
- Basic file operations and data manipulation

## Day 7: ETL Concepts & Simple Data Pipeline

- Extract: Reading from CSV

- **Mini-project:** CSV to MongoDB pipeline
- Error handling in pipelines
- Logging basics
- Testing the pipeline

## Day 8: API Data Pipeline & Automation
**Duration:** 3.5 Hours

### API as Data Source

### API to Database Pipeline
- Extract: API data fetching
- Transform: JSON to structured data

- Introduction to scheduling

Students will be able to:
- ✅ Build complete data pipelines using Python
- ✅ Work with databases (MongoDB) for data storage
- ✅ Extract data from files and APIs
- ✅ Clean and transform data using pandas
- ✅ Create automated data processing scripts
- ✅ Generate basic data visualizations and reports
- ✅ Understand fundamental data engineering concepts
- ✅ Apply best practices in data pipeline development
